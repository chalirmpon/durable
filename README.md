# ทะเบียนครุภัณฑ์ — หน้าเว็บภายนอก (GitHub Pages)

หน้าเว็บกลางไฟล์เดียว ใช้ร่วมได้ทุกหน่วยงาน — เปิดกล้องสแกน QR / บาร์โค้ดแบบสดได้ และไม่มีแถบ "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script"

**วิธีใช้:** เปิด `https://chalirmpon.github.io/durable/?api=` ตามด้วยลิงก์ Web app (`…/exec`) ของหน่วยงาน
— ข้อมูล ผู้ใช้ และรหัสผ่านอยู่ในระบบ Apps Script ของแต่ละหน่วยงานเหมือนเดิม ไฟล์นี้มีแค่หน้าเว็บ ไม่มีข้อมูลหรือลิงก์ของหน่วยงานใด

**อัปเดตรุ่น:** อัปโหลด `index.html` ใหม่ทับไฟล์เดิม (ได้จาก ⚙️ ตั้งค่า → 🩺 ตรวจระบบ / เว็บภายนอก → ⬇️ index.html แบบใช้ร่วมทุกหน่วยงาน)
